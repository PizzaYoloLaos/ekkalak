# Ekkalak — portail des outils

Portail public : https://app.ekkalak.com/

La page regroupe les outils de H-O-M-E, PizzaYolo, NAM PHAK RETREAT, Résidence Bassac, La Cantina et le Centre de commande Ekkalak.
Les versions des outils viennent de `versions.json`, champ `outils` ; celle du portail vient du champ `portail`.
La liste `outils` sert aussi au relevé automatique : une entrée sans tuile ne doit pas être supprimée pour cette seule raison.
Les icônes, le manifeste, le logo et `sw.js` servent à l'installation et au fonctionnement du portail sur téléphone.
Les anciennes versions se conservent dans une archive datée hors du répertoire publié, en plus de l'historique Git.
